# Admisión privada automática y conector local — 31 de julio de 2026

- El radar privado admite automáticamente una fuente solo si el dominio usa HTTPS, `robots.txt` permite la ruta inicial y la fuente alcanza evidencia suficiente para una convocatoria concreta.
- Las fuentes sin esa admisión quedan en seguimiento técnico: no se rastrean ni se convierten en oportunidades por semejanza.
- Cada oportunidad privada publicable conserva la admisión de su fuente como procedencia técnica; después cada especialista decide en aislamiento si le interesa.
- El instalador Windows del puente local descarga ahora un paquete coherente: conector y ejecutor de inventario de metadatos de la misma versión. Ya no invoca el extractor Python ausente ni usa claves de Supabase.
