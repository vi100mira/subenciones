# Fuentes privadas y oportunidades

La cobertura privada de superadministración separa ahora la fuente o programa que está en seguimiento de las oportunidades privadas verificadas. Una fuente no se presenta como oportunidad hasta que el radar conserva evidencia oficial de bases y vigencia.

Cada fuente en seguimiento muestra de forma explícita que tiene cero oportunidades verificadas mientras no se complete esa comprobación. Esto evita transformar programas o páginas de financiadores en convocatorias ficticias.

El escáner reconoce además convocatorias hijas publicadas en una página índice cuando el título y el periodo de apertura/cierre son inequívocos. Cada una conserva la URL oficial de la página y el identificador de su fuente matriz; solo las vigentes se importan como oportunidades privadas.
