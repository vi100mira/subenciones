# Métricas operativas reales del superadministrador

El panel deja de presentar el catálogo nacional de 19 fuentes como una métrica de cobertura. Las métricas principales se calculan desde el inventario global persistido: oportunidades indexadas, públicas abiertas verificadas y entidades privadas detectadas.

El catálogo canónico queda como contexto de procedencia. Cuando no hay lectura territorial BDNS, se muestra una nota de espera y no una cuadrícula repetitiva de conectores pendientes.

La cobertura privada conserva todas las entidades detectadas al desplegar su tarjeta; no recorta la lista a tres elementos mientras muestra un total superior.
