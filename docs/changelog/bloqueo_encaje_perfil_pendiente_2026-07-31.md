# Bloqueo de encaje con perfil pendiente

El encaje de una entidad queda bloqueado si existen sugerencias de perfil de su web pública sin revisar. La interfaz presenta esas sugerencias como paso actual y la API aplica la misma regla, por lo que no se puede eludir desde otra pantalla o petición.

Un perfil revisado anterior sigue siendo historial, pero no se presenta como la revisión de sugerencias nuevas ni habilita el cálculo hasta que el especialista decida sobre ellas.
