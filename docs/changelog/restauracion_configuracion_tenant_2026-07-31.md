# Restauración de configuración de tenant

Se añade un restaurador explícito y con copia local verificable para trasladar la configuración de una entidad entre proyectos Supabase vacíos.

Restaura organización, perfil/configuración, conexión de fuentes, configuración de agentes y una única membresía administradora mapeada por correo. No traslada documentos, recomendaciones, ejecuciones, auditoría histórica, candidatos ni credenciales de fuentes: pertenecen al entorno anterior o requieren una migración documental separada.
