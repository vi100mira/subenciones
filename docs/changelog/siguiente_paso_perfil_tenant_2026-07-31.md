# Siguiente paso visible para el tenant

El Panel de entidad muestra una acción visible cuando el perfil necesita revisión: revisar sugerencias, aprobar el perfil o calcular el encaje. La señal usa únicamente el estado ya autorizado del tenant y no muestra información de otras entidades.

El mismo flujo aparece como nodos en el Panel y en Asistentes para situar el paso actual: URL pública, perfil investigado, revisión experta, encaje y decisión de entidad.
