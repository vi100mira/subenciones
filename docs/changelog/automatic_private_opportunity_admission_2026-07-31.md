# Admisión automática de oportunidades privadas

Se documenta el límite de responsabilidades: el radar admite automáticamente oportunidades privadas globales cuando la evidencia técnica es suficiente; cada especialista de tenant decide de forma aislada si la preselecciona o la ignora. La superadministración supervisa calidad, cobertura e incidencias técnicas, sin aprobar encajes de contenido.
