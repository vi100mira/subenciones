# Cron diario de radares

Se programa el workflow alojado a las 05:15 UTC para ejecutar exclusivamente los radares municipal/social, público general y de financiación privada. El workflow conserva el arranque manual.

Los agentes de investigación de entidad, encaje, documentos, interpretación de bases y redacción siguen bajo demanda: sus decisiones o datos dependen del tenant y de sus permisos explícitos.
